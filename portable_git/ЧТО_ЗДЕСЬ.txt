ЧТО ЗДЕСЬ
=========
Пока ничего. Место под портативный Git.

Git — это штука, которая помнит все прошлые состояния папки и
умеет вернуться в любое из них. Нужна она не для рисования, а для
работы над самой сборкой: сохранять изменения, собирать патчи,
искать, после чего именно что-то сломалось.


ЗАЧЕМ ОН ПОРТАТИВНЫЙ
====================
Чтобы на новом компьютере — или после переустановки Windows —
не искать, что и куда ставить. Скрипт посмотрит, есть ли Git в
системе. Есть — ничего не делает. Нет — скачает сюда и дальше
работает через него.

Сам Git весит около 130 МБ и в историю не едет. Едет только
скрипт, который его достаёт.


КОМУ ЭТО НУЖНО
==============
Только тому, кто чинит и меняет сборку. Если ты просто рисуешь —
эта папка тебе не понадобится никогда, пусть лежит пустой.


КУРИЦА И ЯЙЦО
=============
Скрипт лежит в папке с историей. Чтобы её скачать, нужен Git.
Чтобы получить Git, нужен скрипт.

Разрывается так: на GitHub есть кнопка «скачать архивом», она
работает без Git вообще. Скачал архивом, запустил скрипт, получил
Git — дальше всё как обычно.


СОСТОЯНИЕ
=========
Не сделано. Планируется вместе с обновлялкой.
